# VGP Candidate Repo

## Purpose
Candidate repository for VGP bootstrap work: proposal packaging, validation preparation, and transition from stakeholder support to an operating pilot cycle.

## Current status
Two support signals are already in place:
- support for PA v0 pilot, with a request to validate the first 3 cases;
- support for the VGP proposal and bootstrap pack, with a green light to create the candidate repo.

The next step is operational packaging.

## What this repo is for
- hold the VGP bootstrap pack;
- provide a shared reference point for collaborators;
- track open questions, near-term next steps, and validation cases;
- reduce dependence on scattered chat history.

## Core working logic
1. Package the materials.
2. Prepare the first 3 PA v0 validation cases.
3. Run a compact stakeholder review.
4. Turn feedback into the first pilot loop.

## Milestone 1
- finalize bootstrap pack;
- finalize proposal summary;
- add first 3 validation cases;
- identify open questions;
- prepare the first review round.

## Repository structure
- `docs/bootstrap-pack.md` — working bootstrap pack
- `docs/proposal-summary.md` — compact proposal summary
- `docs/validation-cases.md` — first 3 pilot validation cases
- `docs/open-questions.md` — unresolved questions / assumptions
- `roadmap/next-steps.md` — near-term execution path
