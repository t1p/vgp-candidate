# Proposal Summary

## One-line thesis
VGP moves from discussion to an operating pilot cycle through a lightweight candidate repository, a bootstrap pack, and a small validation loop.

## What is being proposed
Create a shared working container for VGP materials so stakeholders can review one coherent package instead of scattered messages. The package should combine the proposal summary, bootstrap framing, open questions, and validation path.

## Why it matters
Two explicit support signals already exist:
- support for PA v0 pilot with a request to validate the first 3 cases;
- support for the VGP proposal and bootstrap pack with a green light to create the candidate repo.

This means the next phase should be operational, not discursive.

## Pilot path
1. Package VGP materials in the candidate repo.
2. Prepare the first 3 validation cases for PA v0.
3. Run a compact review round.
4. Convert feedback into the first pilot cycle.

## What support has been expressed
- Support for proposal
- Support for bootstrap pack
- Support for PA v0 pilot
- Green light to proceed with candidate repo

## Immediate deliverables
- bootstrap pack
- concise proposal summary
- open questions list
- first 3 validation cases
- near-term roadmap
